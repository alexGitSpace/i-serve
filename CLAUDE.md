# CLAUDE.md

Orientation for an agent working in this repository. **This file holds no facts of
its own** — it says where each fact lives and which file wins on a conflict.
Everything here is a pointer, deliberately, so there is nothing to drift out of
date.

## What this is

A slice of an LLM inference operator's platform — see `README.md` for the legend,
the model choice and the routes, and `docs/layout.md` for the tree. Scale is
deliberately small: the point is that the categories of reasoning are the ones a
real operator uses, and that every number is traceable to the run or the
derivation that produced it.

## Layout

The path-by-path table is in `docs/layout.md`, with a state column. Directories map
one-to-one onto the components this platform is built from; keep that mapping —
the tree is meant to read as a map of the work.

Not every directory in the working tree is part of the repository. Anything the
root `.git/info/exclude` holds out belongs to another repository on another
remote, and a tracked file must never reference it — no path, no filename. A
commit that does is a defect whatever else it gets right.

## Conventions

- **Language.** Repository content is English without exception.
- **Units, hardware figures, model figures, stated assumptions.** SI base units;
  dense FLOPS, never the sparsity row; `config.json` for architecture; and a
  derived floor is never reported as a measurement.
- **New vocabulary.** Every term, abbreviation, metric, formula symbol or named
  config knob introduced by a change is written into `docs/GLOSSARY.md` in the
  same change — definition only, with any argument left in `docs/SLO.md`.
- **Code.** Small steps, every line explained; no large unprompted blocks.
- **Cost.** Anything requiring GPU credits is flagged with its cost in
  credit-hours before running. Everything that can run on `kind` or CPU does.
- **Measurement outranks derivation.** Every number in `docs/SLO.md` and
  `bench/roofline.py` is a prediction until measured. vLLM logs the actual KV
  cache size and block count at startup — that log outranks any derivation in
  this repo (`docs/SLO.md` §9).
- **Generated files are generated.** `docs/benchmarks/predicted-vs-measured.svg`,
  `site/data/`, `docs/benchmarks/README.md` and the runs block of `README.md`
  are produced by `bench/`, regenerated by the pre-commit hook and asserted by
  CI; edit the source, never the output.
